# 理科ラボ 4

小学4年生理科を、条件を変えて結果を確かめるシミュレーションと、問題学習で学ぶブラウザ教材です。季節、天気、月と星、空気・水、温度、電気など、全10単元を収録しています。

## この教材の学び方

スタート画面は、次の2つの入口に分かれています。

- **シミュレーション**：条件を変える → その場で現象が変わる → 短い結果を確かめる
- **問題を解く**：関係を見つける → 予想して確かめる → 理由を考える

LABでは、スライダーや選択ボタンを動かすと、図と結果がすぐに更新されます。リセットと「1つ進める」を使って、同じ現象を条件を変えながら何度でも試せます。

## 収録単元とシミュレーション

| 単元 | LABで試すこと |
|---|---|
| 季節と生き物 | 気温を変え、生き物の成長や活動の変化をくらべる |
| ヒトの体と運動 | 腕の角度を変え、筋肉と関節の動きをくらべる |
| 天気と気温 | 天気と時刻を変え、1日の気温の変化を見る |
| 雨水のゆくえ | 地面の傾きや種類を変え、水の流れ方をくらべる |
| 月と星 | 時刻や日にちを変え、月と星の見え方をくらべる |
| 電気のはたらき | 乾電池の数や向きを変え、モーターの変化を見る |
| とじこめた空気と水 | 中身と押す強さを変え、縮み方と手ごたえをくらべる |
| ものの温度と体積 | 物の種類と温度を変え、体積の変化をくらべる |
| もののあたたまり方 | 物の種類と熱する時間を変え、熱の伝わり方を見る |
| 水のすがたと温度 | 温度を変え、氷・水・水蒸気の変化を見る |

## 問題学習と学習記録

問題は、4年生の「関係付けて考える」学びに合わせて、次の3段階で構成しています。

1. 関係を見つける
2. 予想して確かめる
3. 理由を考える

- 知識、実験・観察の準備、考察の問題を単元ごとに収録
- 条件を分類して実験方法を考える活動を用意
- 答え合わせ、間違いの確認、単元ごとの進み具合を表示
- 全10単元から出題する「まとめチェック」を搭載
- 学習記録は利用中のブラウザ内に保存

## 主な機能

- タブレットで操作しやすいレスポンシブUI
- LABごとのリセットと、時間や状態を一つ進める操作
- 条件の変更に合わせて、図・数値・短い説明を即時更新
- LABは入口を開いたときに読み込み、必要なファイルだけを使う遅延読み込み
- 研究ランク、発見図鑑、おまけコレクション
- 効果音のオン・オフ設定
- 外部API、APIキー、サーバー、データベース、外部フォントを使用しない構成
- GitHub Pagesでそのまま公開可能
