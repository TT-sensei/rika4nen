# 理科ラボ 4

小学4年生理科を、**シミュレーション**と**問題学習**の2つの入口で学ぶ、GitHub Pages向けの教材です。

## 学び方

スタート画面では、次の2タブを切り替えます。

- **シミュレーション**：条件を変える → その場で現象が変わる → 短い結果を確かめる
- **問題を解く**：関係を見つける → 予想して確かめる → 理由を考える

シミュレーションは、スライダーや選択ボタンを動かすと、図と結果がすぐに変わります。リセットと「1つ進める」も用意しています。

## 収録単元・シミュレーション

1. 季節と生き物 — 季節と生き物LAB
2. ヒトの体と運動 — 人の体LAB
3. 天気と気温 — 天気と気温LAB
4. 雨水のゆくえ — 雨水LAB
5. 月と星 — 月と星LAB
6. 電気のはたらき — 電気LAB
7. とじこめた空気と水 — 空気と水LAB
8. ものの温度と体積 — 体積LAB
9. もののあたたまり方 — あたたまりLAB
10. 水のすがたと温度 — 水のすがたLAB

単元の並びと問題データは、改修前から存在する構成を正として維持しています。

## 問題学習と保存

- 既存の知識・実験準備・考察の問題を維持
- 問題の答え合わせ、間違い記録、進捗表示を維持
- まとめチェックは10単元から3問ずつ、計30問をランダム出題
- 旧 `rikaLab4.v1` の学習履歴を `rikaLab4.v2` へ移行
- 学習記録はブラウザの `localStorage` に保存
- 外部API、APIキー、サーバー、データベース、外部フォントは不使用
