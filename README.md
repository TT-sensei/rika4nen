# 理科ラボ 4

小学4年生理科を「関係を見つける → 予想して確かめる → 理由を考える」の3段階で学ぶ、ブラウザ完結型の教材です。

## 収録単元

1. 季節と生き物
2. ヒトの体と運動
3. 天気と気温
4. 雨水のゆくえ
5. 月と星
6. 電気のはたらき
7. とじこめた空気と水
8. ものの温度と体積
9. もののあたたまり方
10. 水のすがたと温度

各単元に、比較して関係を捉える知識4問、予想を伴う実験・観察準備2活動、結果から理由を考える考察3問を収録しています。全10単元から1問ずつ出題する「まとめチェック」も利用できます。

## 特徴

- 4年生で中心となる「根拠のある予想や仮説を発想する力」を重視
- 「くらべる → 関係を見つける → 予想する → 理由を考える」を全単元で反復
- タブレットで押しやすいレスポンシブUI
- 実験・観察の条件、記録、安全をカードで分類
- 不正解時は誤ったカードだけを戻して学び直せる
- 進捗、初回正解、間違えたカードを `localStorage` に保存
- 効果音はWeb Audio APIで端末内生成（初期設定はオフ）
- 外部API、APIキー、サーバー、データベース、外部フォント不使用
- GitHub Pagesでそのまま公開可能
